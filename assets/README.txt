ĐẶT LOGO Ở ĐÂY
================

Copy file logo mặt nạ (ảnh 1 bạn đã gửi) vào thư mục này và đặt tên CHÍNH XÁC:

    logo.png

App dùng file này ở: màn Onboarding, Home, Settings, About, icon app và splash.

Nếu chưa có logo, tạm thời dùng bất kỳ ảnh png vuông nào đặt tên logo.png
để app chạy được, rồi thay sau.
